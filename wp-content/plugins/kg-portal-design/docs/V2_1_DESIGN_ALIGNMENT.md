## Source-of-truth details

- **BG 1.2**: public **outer max-width 480px at all viewport sizes**; no public desktop grid, body/metadata type 16/14/13, H1/H2/H3 28/24/20, card 12px, field 8px.
- **UI 1.2**: filters use native inline disclosure; Apply/Reset have the original state transitions, collapse retains values/results. Source disclosure is inline. No modal/sidebar replacement.
- **DH 1.2**: confirm 320px and 200% zoom; public same composition at 768, 1024, 1440px; desktop admin separate. No unauthorized university images/brand marks.
- **Mockups**: small restrained status indicators, top-aligned metadata, compact FAQ, white background + blue priority CTA, and spacious but not oversized admin cards.

## Intentional limits

This plugin does not create/change page content, split headings into new HTML components, re-label any stored input values, replace official links, change underlying forms, interpret search filters, change API request payloads, approve sources or adjust role rules. It styles the actual markup generated by the installed FE/Admin/Content/Ops versions. Exact element placement in a different locally modified theme may need an additional markup-level design pass after reviewing its **current** code.
